Square Ping

Support

Help for the Square Ping app — a personal tracker for NCAA tournament squares you already own.

Bundle ID com.squareping.app · Operator: MDR Ventures

What this app is

Square Ping helps you track box-pool squares across pools, estimate payouts you set yourself, and get notified when public scores match your digits. It does not accept bets, process payments, or run pools for you.

Quick start

  1. Create a pool for each board you’re in. Pick Winner/Loser or Home/Away — that choice is locked after create.
  2. Add each square you own by tapping the two last digits.
  3. While the app is open, scores check about every two minutes. Pull down on Home to refresh.
  4. Optional: Settings → Enable background alerts for pushes when the app is closed (iOS needs an APNs key configured for your build).

Backup

Settings includes Export backup and Import backup (JSON). Use that before switching phones or clearing data.

Scores look empty

By default Square Ping focuses on tournament-tagged games. In the regular season the scoreboard may look quiet even when the network is fine. Verify a hit against your pool organizer if something looks off — public feeds can be delayed.
